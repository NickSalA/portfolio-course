# Modelo de vinculación

| Entidad | Regla |
| --- | --- |
| Autorización del padrón | Identidad por curso y correo canónico. Una autorización activa puede vincularse a una sola matrícula. |
| Matrícula | Identidad por curso y cuenta. Conserva su identificador y grupo al resincronizar. |
| Grupo | La preasignación inicial se toma del padrón. El grupo de una matrícula existente es el vigente. |
| Vínculo contradictorio | Se conserva para revisión, queda inactivo y no se reasigna a otra cuenta. |
