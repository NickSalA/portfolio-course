# Documentación del proyecto

Esta carpeta reúne el contexto **verificado** de la plataforma académica. El código está en
[`../portfolio-coursse/`](../portfolio-coursse/) y la constitución normativa del proyecto en
[`../.specify/memory/constitution.md`](../.specify/memory/constitution.md). Los documentos aquí
explican el estado y las decisiones; no sustituyen las especificaciones de cada funcionalidad ni
certifican que una migración o un despliegue se haya ejecutado en producción.

Las decisiones y especificaciones previas siguen en
[`../portfolio-coursse/docs/`](../portfolio-coursse/docs/); no se trasladaron ni eliminaron.
La documentación futura de una automatización terminada se ubicará en
`docs/automatizaciones/<nombre-del-proceso>/evaluacion.md`, según la constitución.

Esta estructura está inspirada en las áreas de definición, diseño, calidad/operación, gestión y
entregables. Los apartados de API, UI, despliegue, actas o roles individuales se crearán cuando
existan decisiones o evidencias suficientes; no se mantienen plantillas vacías como documentación.
