# Equipo y flujo de trabajo

La referencia normativa del equipo es la
[constitución del proyecto](../../.specify/memory/constitution.md): define Git Flow, PR revisados,
Conventional Commits, releases con SemVer, verificación antes de integrar y cuidado de secretos.
Este documento no introduce una segunda versión de esas reglas.

La raíz del repositorio contiene `.specify/` para especificación y planificación. El código de la
aplicación está en [`portfolio-coursse/`](../../portfolio-coursse/). Las especificaciones y ADR
anteriores permanecen en [`portfolio-coursse/docs/`](../../portfolio-coursse/docs/). Esta carpeta
`docs/` conserva el contexto global y, al terminar una automatización, su evaluación; no sustituye
los artefactos por funcionalidad generados por Spec Kit.

**Aún por definir con el grupo:** miembros, roles, aprobadores, calendario y responsables de
informes, pruebas y operación. No se creó una asignación de roles, registro de reuniones o
registro de IA porque no hay datos confirmados. La definición de estos acuerdos debe hacerse con
el equipo antes de tratarlos como hechos del proyecto.
