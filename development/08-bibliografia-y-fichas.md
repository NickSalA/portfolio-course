## 8.2 Documentación técnica del stack por incorporar

Para explicar tecnologías concretas, añadir en la versión final las páginas oficiales consultadas de:

- Next.js: Server Actions, validación y seguridad de acciones;
- Supabase: autenticación SSR y Row Level Security;
- PostgreSQL: constraints, transacciones, rangos/exclusion constraints y RLS;
- GitHub: pull request reviews, protected branches y GitHub Actions.

Estas fuentes explican mecanismos; no deben usarse como evidencia académica de beneficios generales.
