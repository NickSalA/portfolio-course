# Plataforma de gestión académica: registro y seguimiento de evaluaciones grupales

Material para el informe y la presentación del curso **Automatización y Control de Software 2026-2**. El proyecto completo busca desarrollar una plataforma; este avance reúne el análisis, la propuesta funcional, el prototipo documental y el plan de desarrollo. Los hitos de semana 8 y semana 16 se organizan en la sección 6.

## Enfoque

El problema parte de la identificación manual de integrantes y la anotación repetitiva de una nota grupal en archivos separados. El seguimiento incorpora consulta de resultados propios y atención de reclamos. La carga del padrón, su validación y la selección de grupos son funciones de apoyo, no proyectos independientes.

Las secciones utilizan lenguaje académico y funcional. El relato del caso procede de las aclaraciones transmitidas por el responsable del proyecto. Las decisiones posteriores de alcance se distinguen de la petición inicial; la regla de aplicación de puntos es un supuesto del equipo. No se atribuyen mediciones o validaciones que no se hayan realizado.

## Preparación de la entrega

1. Revisar con el equipo el alcance y los supuestos, especialmente el cálculo de puntos y la exportación.
2. Completar carátula, integrantes, responsables y fechas.
3. Seleccionar del capítulo 8 la bibliografía utilizada; las candidatas no se presentan como fuentes consultadas.
4. Revisar P-01: actualmente es una representación textual estática con cinco pantallas. Decidir si se convierte en una maqueta visual para la exposición.
5. Maquetar el informe y elaborar el PowerPoint requerido por la guía. Estos archivos de texto son sus insumos, no los archivos finales de entrega.

El borrador integrado reproduce las secciones 01–09. Los cambios futuros deben reflejarse en ambos lugares para conservar una misma versión de objetivos, reglas y conclusiones.
